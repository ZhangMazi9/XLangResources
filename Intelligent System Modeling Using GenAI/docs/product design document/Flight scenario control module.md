# Flight scenario control module
### 1. Module Function

The core function of the Flight Scenario Control Module is to design the flight trajectory, ensuring that the aircraft can strictly follow the preset path to accurately achieve the flight target. By dynamically regulating the flight status, this module provides a basic trajectory basis for the subsequent collaborative work of various functional modules.

### 2. Module Port Specifications

The Flight Scenario Control Module includes 1 input interface and 1 output interface, with specific specifications as follows:

- **Input Interface**: Named "evstart", with a data type of boolean (bool), supporting only two values: "0" and "1". A value of "0" indicates the module is in an idle state, while a value of "1" means the module starts up and enters the working state. This interface is used to receive the start command sent by external modules (e.g., the oper module).

- **Output Interface**: Named "evInstruct", with a data type of real. Its main function is to transmit the flight control commands generated by the module to the Control Bus Module for further parsing and distribution, thereby driving other associated modules to perform corresponding operations.

### 3. Module Working Process

The working process of the Flight Scenario Control Module proceeds step by step in a sequential state order. The duration, command output, and state transition logic of each state are as follows:

1. **Initial State**: After the module is activated, it defaults to the Initial State and waits to receive the "evstart" start command sent by the oper module.

2. **Climb Preparation State**: Upon receiving the "evstart" command, the module transitions from the Initial State to the Climb Preparation State. This state has no duration (instant transition); it immediately sets the "evInstruct" command value to 10000, outputs it externally, and simultaneously transitions to the Climb Start State.

3. **Climb Start State**: This state lasts for 100 milliseconds. During this period, the "evInstruct" command value is set to 11000 and output externally. After the duration ends, the module transitions to the Engine Ignition Preparation State.

4. **Engine Ignition Preparation State**: This state lasts for 50 milliseconds, with no additional command output. After the duration ends, it directly transitions to the Engine Ignition State.

5. **Engine Ignition State**: This state lasts for 250 milliseconds, with no additional command output. After the duration ends, it transitions to the Sector Turning State.

6. **Sector Turning State**: This state lasts for 6850 milliseconds, with no additional command output. After the duration ends, it transitions to the Descent State.

7. **Descent State**: This state lasts for 250 milliseconds. During this period, the "evInstruct" command value is set to 10101 and output externally. After the duration ends, the module transitions to the Secondary Level Flight State.

8. **Secondary Level Flight State**: This state lasts for 7000 milliseconds. During this period, the "evInstruct" command value is set to 10010 and output externally. After the duration ends, it transitions to the Secondary Altitude Reduction State.

9. **Secondary Altitude Reduction State**: This state lasts for 100 milliseconds. During this period, the "evInstruct" command value is set to 10001 and output externally. After the duration ends, it transitions to the Tertiary Level Flight State.

10. **Tertiary Level Flight State**: This state lasts for 8300 milliseconds. During this period, the "evInstruct" command value is set to 10011 and output externally. After the duration ends, it transitions to the Dive State.

11. **Dive State**: This state lasts for 5.5 milliseconds, with no additional command output. After the duration ends, the module finally transitions to the End State, and the current flight scenario control process is completed.
